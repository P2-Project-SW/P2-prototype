# P2-prototype
This is the git repository for the P2 project prototype.

## Guide for running the program
To run this program, first make sure you have esbuild installed. If you do not, run `npm install esbuild` \n
Next, to make sure all packages are installed properly, run `npm install`

Then, to build the project, run either:

`npm run build` -> node.js
`npm run dev` -> for browser build

If you have python installed, an easy localhost server can be started using `python3 -m http.server`

Enjoy :)
